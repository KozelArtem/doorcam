# Дверной глазок

Meizu Note 9 с выключенным экраном обнаруживает движение и хранит MP4 в памяти телефона. Служба камеры создаёт короткие аппаратно закодированные видеосегменты и сохраняет начало прохода. Архив ограничен по объёму. Превью события уходит в Telegram, при потере сети доставка возобновляется после подключения. Телефон использует исходящие соединения. Внешний адрес домашней сети и Raspberry Pi не требуются.

Сайт и бот работают на Cloudflare Workers. Владелец задаёт свой Telegram ID, одобряет зрителей и отзывает права в личном чате. Уведомление содержит фотографию и кнопку запуска Mini App. Внешний браузер использует Telegram OpenID Connect. Сервер проверяет подпись, время и права, выдаёт сессию. Все зрители с доступом получают уведомления после начала диалога с ботом.

В облаке хранятся права и сессии. Durable Object координирует соединения. Видео и список записей передаются по WebRTC с телефона по запросу зрителя. При необходимости используется TURN с краткоживущими учётными данными. Отзыв доступа закрывает активное соединение. При отключении Meizu архив и эфир недоступны до восстановления связи.

Проверка на устройстве включает проход через поле зрения, просмотр через мобильную сеть, нагрев, работу после гашения экрана, лимит памяти и восстановление сети. Для реального развёртывания владелец предоставит собственные настройки Cloudflare и BotFather.
